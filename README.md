# 🏀 Basketball Coach Posters

A React application that recreates basketball coach profile posters using reusable components and modern CSS.

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Features

- Dynamic coach profiles
- Reusable React components
- Modern poster layout
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```
